# the-other-shore-relay

Fichiers temporaires **chiffrés** (AES-256-GCM) en transit vers la chaîne YouTube « The Other Shore ».
Ils sont illisibles sans une clé qui ne figure nulle part dans ce dépôt, et ils sont effacés après usage.

Encrypted temporary files in transit. Unreadable without a key that is never stored here.
